## §1 設計理念：借殼

USB 3.0 Type-A 公頭有 **10 個接點**，但 USB 2.0 只用得到其中 4 個
（VBUS／D−／D+／GND）。剩下的 5 個 SuperSpeed 接點與 1 個 drain，
在一個只跑 USB 2.0 的模組上是**閒置的**。

這個設計把那些閒置腳位拿來走控制線。結果是：

- **一個現成、便宜、機械強度足夠的接頭**，同時承載資料與控制
- **不需要額外的排針或第二條線** —— 板子本身就是插頭
- 對端（NuBri-232c）用一條普通的 USB 3.0 延長線就能連，
  不必自製線材

代價是**這不是一個標準 USB 裝置**：插進電腦的 USB 3.0 孔不會正常工作
（見 §4）。它是一個「借用 USB 接頭的自訂介面」。

## §2 邏輯原理

### 2.1 接頭腳位：哪幾支被挪用

| 接點 | USB 3.0 標準用途 | 本設計實際用途 | 網路名 |
|---|---|---|---|
| 外殼 | Shield | 機殼地 | `Earth` |
| 1 | VBUS | 5 V 輸入 → 經 R1（0Ω／60Ω 磁珠）進電源開關 | `5V+` |
| 2 | D− | **資料**（USB 的 D− 或 UART 的 Rx，見 2.2） | `Rx_DM` |
| 3 | D+ | **資料**（USB 的 D+ 或 UART 的 Tx，見 2.2） | `Tx_DP` |
| 4 | GND | 地 → 經 R2 | `5V−` |
| **5** | StdA_SSRX− | ★ **PowerKey**（開機鍵） | `PowerKey` |
| **6** | StdA_SSRX+ | ★ **Reset**（模組重置） | `DTR_out` |
| **7** | GND_DRAIN | ★ **PowerEN**（電源致能） | `PowEN` |
| 8 | StdA_SSTX− | 未接 | — |
| **9** | StdA_SSTX+ | ★ **PowerEN**（與 pin 7 同網，雙點接觸） | `PowEN` |

PowEN 佔了兩支腳（7 與 9）—— 電源致能是最關鍵的一條線，
雙點接觸可降低單點接觸不良導致的誤斷電。

### 2.2 一對線兩種身分：靠電阻選路

D+／D− 這對線在板上**分岔成兩條路**，只裝其中一組 33 Ω 串阻：

```
                    ┌── R7 33Ω ──► DP ──► U3-59  (模組 USB_DP)   ← USB 模式
  P1-3 (D+) ─ Tx_DP ┤
                    └── R5 33Ω ──► UART_Tx ──► U9-8 (TXS0102 B1) ← UART 模式
                                                    │
                    ┌── R8 33Ω ──► DM ──► U3-60  (模組 USB_DM)   ← USB 模式
  P1-2 (D−) ─ Rx_DM ┤                                │
                    └── R6 33Ω ──► UART_Rx ──► U9-1 (TXS0102 B2) ← UART 模式
                                                    │
                                    TXS0102 (U9)  A 側 1.8V ──► U3-17/18 (Main_RXD/TXD)
```

- **裝 R7／R8** → 直通模組的 USB 埠，主機看到的是 USB 裝置
- **裝 R5／R6** → 走 **TXS0102** 準位轉換（B 側 3.3 V ↔ A 側 1.8 V）
  接到模組的 `Main_TXD`／`Main_RXD`，主機看到的是 UART

網路命名 `Tx_DP`／`Rx_DM` 就是這個雙重身分的直白寫照 ——
**Tx 或 D+、Rx 或 D−，同一條線兩種解讀**。

> TXS0102 的 `OE`（U9-6）由 R37 10 kΩ 拉到 1.8 V、並串 C45 0.1 µF，
> 形成上電延遲：模組的 1.8 V 軌穩定之後準位轉換才致能，避免上電瞬間亂送位元。

### 2.3 電源開關：PowEN 為什麼是「高電位才通電」

```
  VBUS ──R1──┬──────────────► Q4-2 (P-ch source)
             │                       │
            R39 100kΩ          Q4-4 (P-ch drain) ──► 5.0V 軌
             │                       ▲
             └──► Q4-3 (P-ch gate) ──┘
                       ▲
                  Q4-6 (N-ch drain)
                       │
  PowEN ──► Q4-1 (N-ch gate)     Q4-5 (N-ch source) ──► GND
     │
    R38 100kΩ ──► GND        （Q4 = XR6G02L，單封裝 N+P）
```

1. **預設不通電**：R38 把 `PowEN` 下拉到地 → N 通道關 →
   R39 把 P 通道閘極拉到 VBUS → P 通道關 → 5 V 軌沒電。
   主機沒接或沒驅動時，模組不會擅自上電。
2. **PowEN 拉高** → N 通道導通 → P 通道閘極被拉到地 →
   P 通道導通 → VBUS 送到 5 V 軌。

**這就是 NuModem 裡「RTS OFF 才是通電」的來源**：對端把 RTS 接到 pin 7/9，
而 RS-232／邏輯準位的 RTS **解除觸發時線上是高電位**。
UI 上「把 RTS 按滅」＝ 線路拉高 ＝ `PowEN` 高 ＝ 送電。
負邏輯不是軟體的怪癖，是**接線就是這樣**。

> R40（0Ω）跨接在 5 V 軌與 Q4 輸入之間 —— 裝上就等於**旁路整個開關**，
> 變成插上就通電。電路圖註記：「不需要開關模式才裝 0Ω 電阻」。

### 2.4 自動開機脈衝：C30／C31 才是主角

```
  5.0V ──┬── C30 47µF ──┬── PowerKey ──► Q1-5 (Q1B gate)
         └── C31 47µF ──┘        │              │
                                R25 10kΩ    Q1-3 (drain) ──► EG800_PK ──► U3-7 (PWRKEY)
                                 │
                                GND
```

電源開關一導通、5 V 軌上升，**上升緣經兩顆 47 µF 耦合到 `PowerKey`**，
把 Q1B 的閘極短暫拉高 → Q1B 導通 → 模組的 `PWRKEY` 被拉低。
之後電容經 R25 充飽，`PowerKey` 回落、`PWRKEY` 放開。

脈寬 ≈ R25 × (C30＋C31) = 10 kΩ × 94 µF ≈ **0.94 秒** ——
正好對上電路圖註記要求的「拉低 800 ms 開機」。

**所以送電本身就會觸發開機，主機不必再下第二個動作。**
註記說「delay 電容很重要」「一直拉低可能重複開機」就是指這個 ——
電容太小脈衝不夠長開不了機，沒有自動回落則會不斷重複開機。

### 2.5 Reset：反相的

```
  DTR_out ──┬──► Q1-2 (Q1A gate)      Q1-6 (drain) ──► EG800_RST ──► U3-15 (RESET_N)
            │            │
           R24 10kΩ   Q1-1 (source) ──► GND
            │
           GND
```

`DTR_out` 高 → Q1A 導通 → `RESET_N` 被拉低 → **模組被壓在重置狀態**。
`DTR_out` 低（或主機未驅動，R24 下拉）→ Q1A 關 → `RESET_N` 放開 → 模組可運行。

電路圖註記：「DTR 燈亮起(Low)，Reset 腳為 High，EG800 才會啟動！」——
DTR 觸發時線上是低電位，經這一級反相後 `RESET_N` 為高，模組才跑得起來。

另一條註記「`EG800_PK` 拉低期間 Reset 不能為 Low，否則不能開機」
點出兩者的先後：**必須先讓模組離開重置，2.4 的開機脈衝才有意義**。

## §3 操作方式：三條線怎麼配合

NuModem 的開機儀式對應到硬體就是：

| 步驟 | UI 動作 | 線路 | 硬體效果 |
|---|---|---|---|
| 1 | **DTR 打開**（燈亮，低電位） | pin 6 | Q1A 關 → `RESET_N` 放開，模組離開重置 |
| 2 | **RTS 按滅**（高電位） | pin 7／9 | Q4 導通 → 5 V 軌上電 |
| 3 | （自動，無需操作） | pin 5 | 上升緣經 C30／C31 產生 ≈0.94 s 的 `PWRKEY` 低脈衝 → 開機 |
| 4 | 等 `RDY` | pin 2／3 | 模組開機完成，開始回應 AT 指令 |

**順序不能顛倒**：先送電後放 Reset 的話，開機脈衝發生時模組還在重置，
那個脈衝就浪費了 —— 這正是註記第 2 條在講的事。

瀏覽器每次開啟序列埠都會重新拉高 RTS，等於**斷電**，
所以每次重新整理頁面都要重跑一次儀式。

## §4 限制與注意事項

| 項目 | 說明 |
|---|---|
| 🔴 **不是標準 USB 裝置** | pin 5/6/7/9 送的是直流控制準位，不是 SuperSpeed 差動訊號。插進電腦的 USB 3.0 孔，主機的 SS 接收端會看到非預期的直流準位；而且沒有對端拉高 `PowEN`，板子根本不會通電。**必須搭配對應的轉接板使用** |
| pin 8 未接 | `StdA_SSTX−` 保留未用 |
| 模式互斥 | R5/R6 與 R7/R8 只能擇一裝。兩組都裝會讓模組的 USB 埠與準位轉換器同時掛在同一對線上 |
| UART 模式的準位 | 對端須是 3.3 V 邏輯（TXS0102 的 B 側），不是 ±12 V 的真 RS-232 |
| D4 不要裝 | `LRB521S-30T1G` 跨在 `DTR_out` 與 `EG800_PK` 之間，電路圖明確標「D4不要裝！」 |
| 大電流 | 模組峰值 600 mA、傳送數據更高。對端 NuBri-232c 已加兩顆 680 µF 鉭電；本板另預留多顆 470 µF 位置（D 殼鉭電註明「先不要裝」） |

## §5 零件與網路 reference

### 5.1 本文涉及的零件

| 標號 | 型號 | 角色 |
|---|---|---|
| P1 | USB 3.0 Type-A 公頭（10 接點） | 資料＋控制＋供電的唯一介面 |
| Q4 | XR6G02L（單封裝 N+P MOSFET） | 高側電源開關 |
| Q1A | 2N7002 | `DTR_out` → `RESET_N` 反相級 |
| Q1B | 2N7002 | `PowerKey` → `PWRKEY` 反相級 |
| U9 | TXS0102DCU | UART 模式的 1.8 V ↔ 3.3 V 準位轉換 |
| U3 | EG800（LCC 109 pin） | 模組本體 |
| R5／R6 | 33 Ω | **UART 模式**選路 |
| R7／R8 | 33 Ω | **USB 模式**選路 |
| R38 | 100 kΩ | `PowEN` 下拉 —— 預設不通電 |
| R39 | 100 kΩ | Q4 P 通道閘極上拉 —— 預設關斷 |
| R40 | 0 Ω | 旁路電源開關（常時通電），選配 |
| R24 | 10 kΩ | `DTR_out` 下拉 |
| R25 | 10 kΩ | `PowerKey` 下拉，兼開機脈衝的 RC 電阻 |
| C30／C31 | 47 µF ×2 | 開機脈衝的 RC 電容（≈0.94 s） |
| R1／R2 | 0 Ω 或 60 Ω 磁珠 | VBUS／GND 進板，可換磁珠濾雜訊 |
| R37／C45 | 10 kΩ／0.1 µF | TXS0102 `OE` 的上電延遲 |
| D4 | LRB521S-30T1G | **不裝** |
