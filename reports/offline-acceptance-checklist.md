## §1 測試前提

1. **開機儀式**：連線 COM3 → RTS ON→OFF → DTR ON→OFF→ON → 等 `RDY` 與 `+QIND: PB DONE`。
   （或直接按 Hardware 頁的 Power／Reset 鈕操作）
2. **頁面重載＝模組斷電**：重新整理網頁會重開 port、RTS 重新 assert，模組會斷電，必須重跑開機儀式。
3. 建議先按 Basic 頁最前面的 `ATE1` 與 `AT+CMEE=2`（Echo 羣放頁首就是為了這個動線）。
4. 目前模組狀態：urcport＝`uart1`（開機那串 `+CFUN: 1`／`+CPIN: READY`／`SMS DONE` 看得到就對了）。
5. ⚠ **測確認框（紅框鈕）時注意**：Playwright 自動化掛著的期間，原生確認框會被它攔走，
   **你在頁面上看不到、按了像沒反應**（實測 8/5 晚間四個確認框被吃掉，皆已由 Claude 取消、零送出）。
   要測 H4 這類項目前先說一聲，Claude 會暫停自動化讓對話框正常彈出。

## §3 ⚠ 測試陷阱（誤按會干擾後續測試的按鈕）

| 按鈕 | 後果 | 復原 |
|---|---|---|
| 「URC → UART」選 usbat/usbmodem **送出** | **所有 URC 立刻靜默**（寫 NVRAM，重開機也不會好） | 再送一次選 uart1 |
| `AT&F` | AT 設定回原廠（複誦、CMEE 等全重置） | 重按 ATE1＋CMEE=2 |
| `AT+CFUN=1,1` | 模組軟重啟，要重等 RDY | 等開機完成即可 |
| `AT+CFUN=0`／`=4` | 脫網、SIM 停用（=0） | `AT+CFUN=1` |
| `AT+COPS=?` | **阻塞最長 5 分鐘**，期間不能下指令 | 等它跑完 |
| SIM 卡片「Enter PIN」 | 本卡 PIN 未啟用，送出會回錯誤；**若卡有 PIN，連錯 3 次會鎖卡** | 先按 QPINC? 看剩餘次數 |
| GNSS「Set Const」/「NMEA Src On」 | **寫 NVRAM**，跨重開機 | 記下原值再改回 |
| TCP/IP「Act PDP」與各協定頁 OPEN/GET/POST 類紅框鈕 | 會觸發真實連線＝漫遊流量 | 這批留給連線測試，先跳過 |
