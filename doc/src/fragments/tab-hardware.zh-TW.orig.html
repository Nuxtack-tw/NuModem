Hardware —— 開機與序列埠

工作原理：這一頁分成三組。Control 是開機儀式的兩顆按鈕（見前面）； Module 是產品識別；Serial 是 UART 本身的設定。

指令用途怎麼測
ATI廠牌 / 型號 / 韌體版本三合一 開機後第一條就下它。回得出來代表 UART 與模組都活著
AT+GSN模組 IMEI（15 位數字）零流量，隨時可下
AT&V列出所有單字母 AT 參數目前值 ATE / ATQ / ATV 沒有各自的查詢式， 只有這條讀得到
AT+IPR?查 UART 鮑率 出廠 115200。⚠ AT&F 不會重置這個值
AT+IPR=115200;&W設鮑率並存檔 ⚠ 送出後本工具會立刻與模組失聯（手冊：OK 後立即生效）。 復原要斷線→改上方鮑率→重連→重跑開機儀式
AT+QURCCFG="urcport"查 URC 送到哪個埠 收不到 URC 時第一個查這條。要 uart1 才收得到
