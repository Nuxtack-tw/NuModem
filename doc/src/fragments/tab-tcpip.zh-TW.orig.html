TCP/IP —— 資料連線的根

工作原理：這一頁是所有資料協定的地基。 PDP context 只在這一頁啟用與停用， SSL / HTTP / MQTT / FTP 各頁都只放唯讀查詢 —— 因為同一條指令若兩頁各放一份，改一邊就會漏一邊。

標準流程：

AT+QICSGP=1,1,"APN","","",1   ← 設 APN（多數情況不用，模組會自動配）
AT+QIACT=1                    ← 啟用 PDP，最長阻塞 150 秒
AT+QIACT?                     ← 確認拿到 IP
AT+QIOPEN=1,0,"TCP","主機",埠,0,0   ← 開 socket
AT+QISEND=0,<長度>             ← 兩段式送資料
AT+QIRD=0,1500                ← 讀回資料
AT+QICLOSE=0                  ← 關閉
指令要注意的事
AT+QIACT=1 最長 150 秒。成功後一定要用 AT+QIACT? 確認真的拿到 IP
AT+QIOPEN OK 只代表指令收下，成敗看 +QIOPEN: <id>,<err> URC。 563 ＝ 該 connectID 還開著，要先 AT+QICLOSE
AT+QISEND=0,<len> 定長式，模組數滿就送，不必 Ctrl+Z
AT+QISEND=0 不定長式，要用 Ctrl+Z（0x1A）結束。 本工具有「送出 / 送出後自動結束 / 結束」三顆按鈕支援連續發送
AT+QIRD=0,1500 讀到 +QIRD: 0 代表緩衝空了
AT+QPING ⚠ 很多伺服器擋 ICMP，ping 不通不代表 TCP 連不上。 判斷連通性請直接用 AT+QIOPEN
