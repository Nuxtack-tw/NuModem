WiFiScan —— Wi-Fi 掃描與網路定位

工作原理：模組可以掃描周邊 2.4GHz 熱點，回報 MAC、RSSI、頻道。 這些資料本身可以用來做「網路定位」—— 把熱點資訊送到雲端換座標， 室內也能定位，不需要衛星。

指令要注意的事
AT+QWIFISCAN 結果在 OK 之後非同步回報，最長等 13 秒。 本機出廠上限 5 個熱點
AT+QWIFISCAN=? ⚠ 本機實回的範圍是「輪數 1-3、熱點上限 4-10」， 應用文件寫的 1-6 與 4-30 是錯的
AT+QLBS QuecLocator 網路定位。需要向 Quectel 申請 token， 沒有的話一律回 702
QuecLocator 沒有官方文件收錄在本專案。 那一組按鈕的說明只寫 2026-08-07 的實測事實， 從子項名稱推得的語意都標了「推測」。實測已知： 沒 token 與假 token 都回 702、token 讀回時被遮成 *、 設定用小寫鍵但讀回是駝峰（latorder → latOrder）。
