HTTP —— 網頁請求

工作原理：HTTP 是三段式的： 先設 URL（本身就是兩段式）、再發請求、最後讀回應。

AT+QHTTPCFG="contextid",1
AT+QHTTPURL=<URL長度>,80   ← 等 CONNECT 再送 URL，不可附加 CR/LF
AT+QHTTPGET=80            ← 結果在 +QHTTPGET URC
AT+QHTTPREAD=80           ← 讀回應。真正的結束標記是 +QHTTPREAD: 0
陷阱說明
URL 長度不可附加 CR/LF，會被算進長度
CONNECT 等多久手冊寫「within 125 s」—— 等提示符的 timeout 必須設到 125 秒，不能沿用 MQTT 的 5 秒
AT+QHTTPREAD 的結束 data mode 中的 OK 不是結束， 最後獨立一行的 +QHTTPREAD: 0 才是
分段 GETAT+QHTTPGETEX 走 HTTP Range。 ⚠ 只在 requestheader=0 時可執行； 伺服器不支援 Range 就會回 200 加整份內容
